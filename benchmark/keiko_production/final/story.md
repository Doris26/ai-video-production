# 景子老師的課外授業 — Scene Script

## Voice Rule: NEVER overlap. Each scene uses EITHER narration OR women talking, never both.

## Characters
| Character | Voice | Rate | Pitch | Used For |
|-----------|-------|------|-------|----------|
| **Narrator** | zh-CN-YunxiNeural | -15% | -8Hz | Scene description, action |
| **景子** | zh-CN-XiaoyiNeural | -25% | -5Hz | Dialogue, emotional lines |

## Audio Mix Per Scene Type
| Type | Voice | Ambient | SFX |
|------|-------|---------|-----|
| Scene-setting | Narrator only | Seedance -10dB | None |
| Dialogue | 景子 only | Seedance -15dB | None |
| Emotional | 景子 only | Seedance -15dB | Soft crying |
| Explicit | 景子 only | Mute | Moaning -5dB |
